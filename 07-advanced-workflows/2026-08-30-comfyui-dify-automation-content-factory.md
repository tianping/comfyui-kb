# ComfyUI + Dify 自动化：从一句话到批量出图，搭建你的 AI 内容工厂

> 来源：新智元 · 2026-08-30
> 链接：https://mp.weixin.qq.com/s/TA6j1tPAtwyKyHM6BENcQw

## 核心思路：Dify 负责"想"，ComfyUI 负责"做"

- **ComfyUI = 执行引擎**：根据精确参数和提示词生成图片/视频，但不会思考
- **Dify = 编排中枢**：调用大模型做自然语言理解、剧本生成、分镜拆解、提示词优化，但本身不能生成图片/视频
- 两者通过 API 连接：输入故事大纲 → Dify 拆分镜 → 生成提示词 → 调 ComfyUI 出图 → 调视频模型生成片段 → 输出完整素材

## ComfyUI API 基础

启动后默认 `http://127.0.0.1:8188`，提供 REST API：

| 接口 | 方法 | 用途 |
|------|------|------|
| `/prompt` | POST | 提交工作流 JSON，返回 prompt_id（异步） |
| `/history/{prompt_id}` | GET | 查询任务状态和结果 |
| `/upload/image` | POST | 上传图片（图生视频、IP-Adapter 参考图等） |

**工作流 JSON 获取**：ComfyUI 中设置好工作流 → 菜单 → 导出（**API 格式**）→ 得到含节点 ID 和输入参数的 JSON 模板，Dify 把用户输入填入对应节点后提交。

> 关键：导出时选"API 格式"而非普通保存。在 ComfyUI 设置中开启"显示节点 ID"便于定位。

## Dify 中配置 ComfyUI 工具

1. **准备 JSON**：ComfyUI 中搭好工作流（文生图/图生视频），导出 API 格式 JSON，确保有可替换的变量节点（如 CLIP Text Encode 的 text 输入）
2. **添加工具节点**：Dify 工作流编辑器 → 添加"工具"节点 → 选 ComfyUI → 填 API 地址 + 粘贴 WORKFLOW JSON
3. **连接变量**：把 LLM 生成的提示词变量连到 ComfyUI 工具对应输入。Dify 自动识别 JSON 中的文本输入节点
4. **设置输出**：返回图片 URL，可展示或传给后续节点（视频生成、字幕等）

## 场景一：智能提示词生成器

```
开始节点(用户输入) → LLM节点(自然语言→专业提示词) → ComfyUI工具(出图) → 结束(返回图片URL+提示词)
```

- LLM 模板示例：`你是一个AI绘画提示词专家。将以下描述扩展为详细的Stable Diffusion提示词，包含主体、场景、光照、风格、画质标签。用户描述：{{user_input}}`
- 输出 positive_prompt 和 negative_prompt
- 价值：不会写提示词的人也能出好图，大模型可根据不同模型（SDXL/Flux2）自动调整提示词风格

## 场景二：批量分镜图生成

```
开始(剧本/大纲) → LLM1(拆分镜→JSON数组) → LLM2(每分镜→提示词) → Loop(遍历→调ComfyUI) → 结束(返回所有分镜URL)
```

**角色一致性保障**：
- Dify 设置全局角色变量（参考图 URL、角色描述），每个分镜提示词都包含角色描述
- ComfyUI 工作流固定加载 IP-Adapter 和角色 LoRA

**批量技巧**：ComfyUI 本身支持队列，Dify 可一次提交多个任务。Dify 的 Loop 节点通常串行，并行需多个工具节点同时调用。

## 场景三：短剧全自动生产线

完整流水线：

1. **剧本生成**：用户输入题材+大纲 → LLM 生成完整剧本（对话、场景、镜头指示）
2. **分镜拆解**：剧本 → 分镜列表（景别、角度、运动）
3. **角色设定**：LLM 生成外貌描述 → ComfyUI 生成角色参考图（IP-Adapter 锁定）
4. **分镜图批量生成**：Loop → ComfyUI（Flux2+IP-Adapter+ControlNet）
5. **图生视频**：遍历分镜图 → ComfyUI（Wan2.1/LTX）
6. **配音生成**：TTS API（如 CosyVoice）
7. **后期合成**：FFmpeg/剪辑 API → 视频+配音+字幕 → 成片

**开源实现参考**：kt-ai-Studio（GitHub: oskey/kt-ai-Studio），核心流程：结构化 Prompt 模板 → LLM 生成人物场景 → 生成基础素材 → LLM 生成最终提示词 → ComfyUI API 执行 → 输出图像或视频

> 现实限制：全自动还不能完全替代人工。分镜图约 30% 不合格需重生成，视频片段需挑选，配音需调整。但自动化干掉 80% 重复工作，人只负责审核和微调。

## 常见问题

| 问题 | 解法 |
|------|------|
| Dify 调 ComfyUI 超时 | 异步模式：提交返回 prompt_id → 轮询节点定期查询 → 完成后取结果；或加长超时 |
| 怎么找到并修改 JSON 中的节点 | ComfyUI 设置→显示节点 ID，JSON 中以 ID 为 key、inputs 为 value，Dify 自动识别可修改的文本输入 |
| 本地 ComfyUI 怎么让云端 Dify 访问 | ngrok/frp 内网穿透，或部署到云服务器（阿里云 PAI-EAS 提供 ComfyUI 云端部署） |
| 生成的图片怎么获取 | 拼接 `http://127.0.0.1:8188/view?filename=xxx.png`，Dify 工具通常自动处理 |
| 需要写代码吗 | 基础场景不需要（可视化工作流+内置工具），复杂场景可能需 Python 代码节点做中间处理 |

## 安全与成本

- **API 安全**：ComfyUI 暴露公网必须设 `--api-key` 启动参数，否则任何人可调你的 GPU
- **成本控制**：Dify 中设生成数量上限，批量前先预览前几张质量确认再全量跑
- **错误处理**：工作流加错误判断节点，失败则重试或跳过，不阻塞整条流水线

## 关键启示

- 本质：把人的创造力和 AI 的执行力分开——人负责创意方向和质量审核，AI 负责重复生成
- 从最简单的智能提示词生成器开始，逐步扩展，不要一开始就追求全自动化
- 流水线搭好后，每部新短剧的边际成本越来越低
