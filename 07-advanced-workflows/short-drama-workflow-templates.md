# ComfyUI 短剧工作流模板库：5 个开箱即用的工作流

> 来源：[ComfyUI工作流模板库：5个开箱即用的短剧工作流，导入就能用](https://mp.weixin.qq.com/s/Pd1FvSay1RbPd35fLoCFng) · 公众号「殴瘸你只腿」 · 2026-08-24

短剧制作最大的时间浪费不是生成慢，而是每次重新搭工作流。这 5 个模板覆盖全流程：**角色一致性、批量分镜出图、图生视频、视频修复、多角色同框**。搭好一次，每集复用。

## 使用前的准备

- **ComfyUI Manager**：必备
- **IP-Adapter 节点**：`ComfyUI_IPAdapter_plus`（角色一致性核心，附带 InsightFace 依赖）
- **ControlNet**：内置节点，下载对应模型即可
- **视频节点**：Wan / H3 / LTX 各有官方或社区节点
- 模型：基础大模型（Flux/SDXL）、IP-Adapter、ControlNet、视频模型放对应 models 子目录

建议建一个「短剧模板」文件夹，5 个工作流存为 .json，直接拖拽导入。

## 工作流一：角色一致性锁定

**场景**：同一角色的不同角度/表情/场景分镜图，保证全剧角色统一。

节点链：Load Image（正面参考图 1024x1024）→ CLIP Vision Encode → IP-Adapter Apply → Load LoRA（可选）→ ControlNet（OpenPose/Depth）→ CLIP Text Encode → KSampler → Save Image

关键参数：
- IP-Adapter 权重起始 0.65；角色漂移调高、画面僵硬调低
- 多参考图串联：正面 0.6-0.8，侧面 0.2-0.4
- Start At/End At 默认全程 0.0-1.0；要构图自由设 0.2-0.8
- ControlNet：姿态要求高 0.8，仅参考 0.4
- KSampler：步数 20-30，CFG 5-7；竖屏 768x1344 或 832x1216
- 参考图 2-3 张最佳（正面+45°侧面+全身），超过 5 张反而身份模糊

技巧：用 AI 先生成高质量正面肖像 + ADetailer 面部修复再作参考图，比随手拍效果好。换衣要在提示词写明新服装；侧脸崩就加侧面参考图或降 IP-Adapter 权重。

## 工作流二：批量分镜出图

**场景**：一集 15-20 个分镜，批量输入批量输出。

核心：角色一致性子工作流作基础 + Prompt List（一行一个提示词）+ Batch Index 迭代取词 → 统一 KSampler 参数 → 自动编号保存（shot_01...）

关键参数：
- 固定基础种子 + 每帧递增（control_after_generate=increment），风格统一又有变化
- 统一分辨率不混用；一次跑 5-8 个分镜防显存溢出

进阶：剧本分镜整理成 JSON，通过 Dify 的 ComfyUI Tool 节点全自动批量（掘金有「零代码AI漫剧生产线」教程）。

省时原则：分镜是给视频生成用的素材，80 分够用，批量跑完统一筛选，不满意的单独重生成。

## 工作流三：图生视频

**方案 A：Wan2.2 I2V（本地/开源）**
- 模型 wan2.2_i2v_14B_fp8_scaled（8GB 显存用 fp8）
- 步数 20-30，CFG 5-6，81 帧≈5s@16fps 或 121 帧≈5s@24fps
- 8GB 显存 5 秒视频约 5-8 分钟，失败率 15-20%

**方案 B：MiniMax H3（云端/本地 INT4）**
- 官方模板库路径：工作流→浏览模板→视频→MiniMax H3
- All-in-One：最多 9 张视觉参考 + 原生音频，最长 15 秒 2K
- 文字渲染突出，分镜含字幕/招牌首选

**方案 C：LTX 2.3 20 宫格（长片段）**
- 20 张分镜拼 4x5 大图，一次生成约 70 秒连贯视频
- 适合蒙太奇/回忆杀/快速转场；有崩溃风险，先 5 宫格测试

**混合策略**：对话特写用可灵（一致性好），中景全景用 Wan（零成本），文字动效用 H3，长片段用 LTX。每个模型保存独立工作流按镜头切换。

## 工作流四：视频修复与增强

按顺序流水线处理：**闪烁去除 → 降噪 → 超分 → 插帧 → 口型同步**

| 模块 | 工具 | 要点 |
|------|------|------|
| 去闪烁 | VideoHelperSuite 抽帧 + AnimateDiff/Deflicker | 帧间混合强度 0.3-0.5，太强运动模糊 |
| 超分 | Real-ESRGAN / Ultimate SD Upscale | 动漫用 x4plus_anime，真人用 x4plus；原片差先降噪 |
| 插帧 | RIFE / GMSSDI | 16fps→24 插 1.5 倍；高速运动可能重影 |
| 口型 | Wav2Lip（真人）/ SadTalker（动漫） | 提取人脸帧→输入音频→替换回原视频 |

每个模块存独立子工作流，不要一次性全跑。

## 工作流五：多角色同框

**方案 A：多 LoRA 叠加**——每个权重调低到 0.3-0.4（单个 0.6 会互相干扰），配 Region Prompt 分区 + OpenPose 双姿态。三个以上角色不建议纯 LoRA 叠加。

**方案 B：Region Prompt 分区**——画面左右分区各挂各的参考图和提示词，全局描述场景光照。区域边界可能融合问题，调大小和重叠度。

**方案 C：分别生成+后期合成**——各自生成（透明/纯色背景抠图）+ 背景图 + Image Composite 或剪映合成。最可控但步骤多，只用于关键镜头。

建议：正反打为主（A 特写→B 特写→双人中景），真同框每集控制 2-3 个。

## 工作流管理建议

- `user/default/workflows/短剧模板/` 下命名：01_角色一致性.json ... 05_多角色同框.json
- Group 节点（Ctrl+G）分区框选命名
- 固定参数设默认，可变参数（提示词/参考图/权重）放工作流最上方
- 大改另存新版本（v2），可回退
- 8GB 显存：fp16 混合精度 + 视频 fp8 量化 + 批量不超 8 张 + 视频分段

## 核心观点

工作流的本质是把重复的事情自动化，把精力留给真正需要创造力的部分——剧本、节奏、情感。花一个下午把 5 个工作流搭好调通保存，然后不要再折腾工具，把剩下的时间用来写一个好故事。
