# Hermes全自动LoRA训练实战：从装环境到出图零代码

> 来源：微信公众号文章 · 2026-08-11 · [原文链接](https://mp.weixin.qq.com/s/7vGymdDCCjm6S_BRTdPu6w)

## 概述

作者用 Hermes AI 智能体全自动完成 LoRA 训练全流程——从安装环境、处理数据集到训练出图，全程没写一行代码，没点一次 GUI 按钮。

## 核心观点

> 数据集的质量决定了 LoRA 的上限。

高质量的10多张图认真标注，效果可能比500张粗处理还好。

## 全流程记录

### 1. 底模选型
- 选择 **Anima**（二次元生成模型）作为底模

### 2. 数据集准备
- 手头约2900张图，Hermes 从中挑了500张
- 自动处理参数：去掉不必要画师标签，去掉 masterpiece/best quality 质量词，统一加触发词 `shinsei_fukumen`
- 最终：512张图 + 512个标注文件，全部自动完成
- **不足**：标注较粗糙，只是简单去重拼接，没有精细调整

### 3. 安装环境（Hermes自动完成）
- Hermes 用 git 拉 `kohya_ss` 到本地
- 装好 Python 依赖，配好 CUDA 环境
- 一句「帮我装一下」，剩下全自动
- **踩坑**：RTX 5070 Ti 的 Blackwell 架构 CUDA 12.0 跟 xformers 不兼容，必须用 `--sdpa` 参数替代。Hermes 自己踩了自己修

### 4. 训练参数

| 参数 | 值 |
|------|-----|
| 图片数 | 512张 |
| 分辨率 | 1024 |
| LoRA维度 | 32 |
| LoRA Alpha | 16 |
| Epoch | 50 |
| Batch Size | 2 |
| 保存精度 | bf16 |
| GPU | RTX 5070 Ti 16GB |
| 显存占用 | ~70% |
| 训练时长 | 约10小时40分钟 |

- LoRA 模块覆盖 Qwen3 Text Encoder 的196个模块 + Anima DiT 的280个模块
- 最终保存 .safetensors 文件，127MB

### 5. 效果展示
- 用训练好的 LoRA + Anima 底模，从 anima-tools 节点（基于 animadex.net 数据库）获取12个原神角色提示词
- 生成12张角色图（雷电将军、胡桃、甘雨、可莉等）
- **效果评价**：第一次训练不太成功，风格特征学到了一些但跟原图有差距，容易出现不合理的身体比例

### 6. 云端替代方案
- 本地 GPU 不够可用 ModelScope AIGC 专区云端 LoRA 训练

## 关键经验

1. **数据集最重要**：花时间选图比调参数有意义得多
2. **AI 智能体确实能省事**：一句话搞定安装、处理数据、训练
3. **第一次训练别期待完美**：先跑通流程再说
4. **少而精 > 多而粗**：10+张高质量图认真标注，可能比500张粗处理好
5. **5070 Ti Blackwell 架构注意事项**：CUDA 12.0 不兼容 xformers，需用 `--sdpa` 替代
