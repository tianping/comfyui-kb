## 原生视频剪辑（VideoTrim / VideoCrop）

接法（插在视频链路中间）：

```
Load Video(VIDEO) → VideoTrim(video) → Save Video / Preview Video
```

- VIDEO_EDIT 控件在节点上就能拖起止点，不用开别的软件
- HEVC 重封装为 mp4/mov（编码 hvc1，#15809），导出兼容性更好

**5 分钟实操**：
1. 画布空白处双击 → 搜 Load Video → 选本地 mp4
2. 再搜 VideoTrim（视频分类下）
3. Load Video 的 VIDEO 输出 → VideoTrim 的 video 输入
4. VIDEO_EDIT 控件设 start=3.0、end=8.0
5. VideoTrim 输出 → Save Video（或先接 Preview Video）
6. Queue Prompt

**检查点**：预览只有 3~8s = 成功；没变化 = 起止区间没设上；"VIDEO 类型不匹配" = 接错端口。

**踩坑**：忘了 Save Video 的编码选项，导出 webm 播放器不认——v0.35.0 里 HEVC/hvc1 兜底，导出前看一眼编码格式。

## 官方 H3 Max / Max Turbo：别和社区 LoRA 搞混

9 月中文圈写滥的是「H3 Turbo LoRA 本地加速」——那是社区方案，往底模挂 LoRA。v0.35.0 是把**官方托管**的 H3 Max / Max Turbo 选项直接合进 H3 text-to-video 节点和首尾帧（first-last-frame）节点：

| 方案 | 来源 | 怎么用 |
|------|------|--------|
| 社区 H3 Turbo LoRA | 第三方训练 | 当 LoRA 挂到底模 |
| 官方 H3 Max / Max Turbo | v0.35.0 内置节点选项 | 节点里直接选，走官方 API |

建议：新手优先用官方节点选项，配置少、不容易翻车；社区 LoRA 适合玩熟了想本地微调的场景。别看见"Turbo"就当成一个东西。

**5 分钟实操（认出 + 选中）**：
1. 加 H3 Text to Video 或 H3 First Last Frame 节点
2. 参数区找"模型/预设"下拉，多出 H3 Max / H3 Max Turbo（#16025 / #16094）
3. 选 H3 Max Turbo（更快）
4. 把原本接社区底模的 prompt/首尾帧输入改接到官方节点

**检查点**：下拉有 H3 Max / Max Turbo = 版本对（v0.35.0+）；选了报 key/401 = 去设置配官方 API key（作者第 22 篇专讲）；根本找不到 = 没升到 v0.35.0。

H3 系列其他增强（v0.35.0 一并更新）：PDD LoRA 支持（#15908）、H3 Fun Union 里用 references（#16020）、H3 Max 进 Reference 节点（#16041）、VAE 改成可选（#16065）、controlnet 重构为 model patch（#15975）、支持 DiffSynth-Studio / ModelScope 训练的 H3 / HiDream O1 LoRA（#15662）、移除不再必要的 H3 显存 workaround（#16103）。

## 3D 网格节点：File3DToMesh + TRELLIS 降显存

- **File3DToMesh**（#15919）：解析 GLB/GLTF/OBJ/STL 为 MESH，下好的 3D 模型文件不用转格式就能用
- **TRELLIS 降显存/内存**（#16034 / #16054）：4060 用户也能跑 3D 生成
- **Preview3DAdvanced / PreviewGaussianSplat / PreviewPointCloud** 把临时路径标清楚（#16038）

**5 分钟实操（GLB → MESH）**：
1. 搜 File3DToMesh 加节点
2. 选/拖入模型文件（GLB/GLTF/OBJ/STL 四种都支持）
3. MESH 输出 → Preview3DAdvanced（或你自己的 3D 处理链路）
4. Queue Prompt，预览里模型转起来 = 成功

**踩坑**：STL 文件但节点默认 GLB，报"格式不支持"——四种都吃，确认节点上的格式选择跟文件后缀一致再跑。显存爆 → 开 --lowvram / --medvram，或换 TRELLIS 降显存版。

## 4060 / 8G 专项

- **Sparse Attention**（#16072）：长序列视频（帧多、分辨率高）注意力优化，4060 跑长视频卡顿优先试
- **TRELLIS 降显存**（#16034 / #16054）：3D 生成显存占用下来，8G 卡能进 3D 工作流，启动仍建议 --medvram / --lowvram
- **H3 显存 workaround 移除**（#16103）：官方说不再必要，官方 H3 节点路径更轻了；老自定义 H3 节点报错先确认该不该撤掉自己加的 workaround

## 五个坑一次说全

1. 照抄二手把 v0.34.0 当 v0.35.0，节点对不上
2. 视频导出格式播放器不认，没看 Save 的编码选项
3. 把社区 H3 Turbo LoRA 和官方 H3 Max 节点混为一谈
4. 3D 节点显存爆，没开 --lowvram 也没试 TRELLIS 降显存版
5. 升级后老工作流残留的 H3 显存 workaround 没撤，反而报错

## 升级后工作流要改的四处

1. "导出→外部剪"的视频裁剪 → 换 VideoTrim / VideoCrop，先 Preview 确认区间
2. 用 H3 出视频 → 看 text-to-video / 首尾帧节点里有没有多出 H3 Max / Max Turbo，有就优先用官方
3. 3D 链路 → 换 File3DToMesh 吃 GLB/GLTF/OBJ/STL，别再手动转格式
4. 老 H3 显存 workaround 节点撤掉，交给官方轻量路径
