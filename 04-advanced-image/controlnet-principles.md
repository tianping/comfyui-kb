# ControlNet 核心原理拆解：它如何让 AI 绘画从随机走向可控？

> 来源：微信公众号「老王自学ComfyUI」，2026-08
> 原文：https://mp.weixin.qq.com/s/7zMGJBh5NoPJhVCFSCUxaw

## 为什么需要 ControlNet

早期 SD 系列有一个痛点：提示词写得很好，但生成的构图、姿态、空间布局无法精确控制。比如提示「双手叉腰的女孩」，最后可能生成双手下垂的图——仅靠文本难以精确表达复杂布局。

ControlNet 的本质：**在文本到图像的单一映射基础上，增加一条并行的「空间条件→图像」通道**，条件变成「文本+空间条件」的多模态输入，画面结构自然可以精准控制。

## 核心原理：冻结+克隆+零卷积

### 1. 冻结底模

ControlNet 加载时，**底模权重完全冻结**，不修改任何原始参数。这样底模的通用生成能力不会被削弱，也不存在权重覆盖问题。

### 2. 克隆编码器

复制底模的 **UNet 编码器及中间层**（不是整个 UNet），作为可训练副本，在特定任务数据集上训练，专门学习读懂某种条件图。

**为什么不克隆整个 UNet？**
- 空间条件图（边缘/姿态/深度）本质是空间信号，只需要编码器部分把它翻译成特征向量
- 克隆整个 UNet 容易导致参数间过拟合
- 只克隆编码器减少参数量，降低训练成本

### 3. 建立连接：零卷积

冻结的底模层与克隆副本通过**零卷积层（Zero Convolution）**连接。

零卷积的妙处在于：训练初始时它输出全零，相当于 ControlNet 对模型完全没有影响——训练过程中参数从零逐渐增长，逐步把条件信号注入底模。效果越好越增强，而底模原始能力始终不受影响。

## ControlNet 与底模的强耦合关系

ControlNet 与底模**强耦合**，不同底模不能通用：

- SD1.5 训练的 ControlNet → 不能直接用于 SDXL、SD3.5
- 原因：不同底模网络结构不同（通道数、注意力层数、机制维度），维度不匹配会导致权重加载失败

**通俗理解**：SD1.5 的 ControlNet 是一个 1.5L 自然吸气发动机，只能装在 SD1.5 这辆车上；SDXL 是 SUV，Flux 是新能源电车，物理接口和通信协议完全不同（UNet 架构 vs DiT 结构），换不了。

> 💡 目前 SD1.5 的 ControlNet 生态最成熟；Qwen-Image、Flux、LTX、Wan 等主流模型均已进行不同程度的适配。**每个基础模型都要用自己的 ControlNet。**

## 统一 ControlNet 趋势

以前一种控制条件对应一个模型（Canny 一个、OpenPose 一个、Depth 一个），现在趋向于**一个模型支持多种条件**：

- 代表：Qwen-Image-ControlNet-Union，一个模型同时支持 Canny、Soft Edge、Depth、Pose 四种类型
- SDXL 的 ControlNet Union、FLUX.2-dev-Fun-ControlNet-Union 都是这个方向

从「专一路线」切换到「万能适配」。

## ControlNet 四大分类

### 一、轮廓与边缘类

通过提取线条/轮廓控制构图，最常用最直观。

| 类型 | 说明 |
|------|------|
| Canny（硬边缘） | 提取清晰锐利的边缘，控制力强 |
| SoftEdge / HED（软边缘） | 柔和有艺术感的边缘，控制力比 Canny 宽松 |
| Lineart（线稿） | 精细线稿，适合动漫/插画 |
| Lineart Anime（动漫线稿） | 专门针对动漫风格 |
| MLSD（直线检测） | 提取建筑/室内场景的直线结构 |
| Scribble（涂鸦） | 将随手涂鸦转化为生成引导 |
| Shuffle（随机洗牌） | 打乱图像风格再进行控制（特殊类型） |

### 二、空间与深度类

通过三维信息控制画面空间布局。

| 类型 | 说明 |
|------|------|
| Depth（深度图） | 控制前后景关系和透视效果 |
| Normal（法线贴图） | 控制物体表面朝向，表现材质和立体感 |

### 三、姿态与对象类

精准控制特定元素（如人物）的形态和位置。

| 类型 | 说明 |
|------|------|
| OpenPose（姿态） | 提取人体骨骼关键点，精准控制动作 |
| Segmentation（语义分割） | 用色块区分不同物体，控制各元素布局 |

### 四、功能与处理类

用于实现特定功能。

| 类型 | 说明 |
|------|------|
| Inpaint（重绘） | 局部重绘 |
| Tile（分块） | 高清放大、细节修复 |
| IP2P（指令式编辑） | 根据文本指令修改图像 |
| TemporalNet | 视频生成，保证帧间连贯 |
| Reference（参考） | 无需额外模型的参考控制方式 |

**特殊类型**：animal_openpose（动物姿态）、qrcode（艺术二维码生成）等。

## 学习建议

不用关注模型新旧，**重点了解每种控制条件的作用和应用场景**。后续遇到新模型时，只要查该模型是否有对应的 ControlNet 即可复用同样的思路。
