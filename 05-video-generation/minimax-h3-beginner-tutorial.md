# ComfyUI + MiniMax H3 图生视频纯小白教程

> 来源：[别花钱买课了，ComfyUI+MiniMaxH3图生视频纯小白教程](https://mp.weixin.qq.com/s/PJPKE0gWXpUOHS7W_kOJvw) · 2026-08-12

## 概述

别花钱买课。ComfyUI + MiniMax H3 图生视频其实就三步：下载 ComfyUI → 软件内自动下载 H3 模型 → 图生视频。其他生图/生视频模型用法基本一致，一通百通。

## 三步操作

### 第一步：下载安装 ComfyUI
1. 官方下载地址：https://comfy.org/download
2. 下载安装桌面版（和下载微信电脑版难度差不多）
3. 首次启动自动准备运行环境，耐心等待
4. 如果提示更新，记得更新

### 第二步：下载 MiniMax H3 模型
1. ComfyUI 左侧竖排按钮 → 选择「模板」
2. 找到「视频」类型，选择「MiniMax H3 图生视频」
3. 会弹窗报错（缺少模型文件），点击「查看详情」→「全部下载」
4. 等待模型下载完成

**为什么会缺4个模型？** 一个完整图生视频工作流需要：
- **扩散模型**：负责生成视频画面（核心模型）
- **文本编码器**：理解提示词（辅助，可替换，如换去审查版）
- **VAE**：把模型内部数据还原成视频画面（必要工具）
- **图生视频工作流 JSON**：把上述模块按正确方式连接

### 第三步：开始图生视频
1. 上传一张图片
2. 描述怎么动（写提示词）
3. 点击「运行」

最左侧两个框是模型介绍和相关连接，不影响操作。

## 硬件需求
- 视频生成模型非常吃显存内存
- 测试环境：16G 显卡 + 32G 内存，基本跑满

## MiniMax H3 能力
- 最高输出 15 秒、2K 原生双声道视频
- 支持图生视频（图+提示词→视频）

## 注意事项
- 这是官方最简单工作流，给纯小白跑流程用
- 工作流可以很复杂，模型有不同量化版本
- 有去审查版本可生成无底线视频
- 出满意视频还需学「镜头语言」：清晰描述脑中画面
