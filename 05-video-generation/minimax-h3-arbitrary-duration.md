# MiniMax H3 突破15秒：ComfyUI 接力插件实现任意时长视频

> 来源：[让 MiniMax H3 突破 15 秒](https://mp.weixin.qq.com/s/hQJ3QJ4HJw28WG0aCNY93A) · 2026-08-12

## 概述

MiniMax H3 单次只能生成十几秒视频。本文介绍两个 ComfyUI 插件组合使用，通过"接力"机制实现任意时长视频生成，解决段间画面跳跃和音频断裂问题。

## 问题分析

H3 单次生成约 5 秒/124 帧，拉长到 15 秒级别显存就扛不住。分段生成再拼接的问题：
- **画面**：硬切、叠化、转场尚可解决
- **音频**：H3 画面和声音一起生成，两段独立视频的背景音乐不是同一首录音，人声节奏/气息/咬字对不齐，接缝处明显露馅

## 两个核心插件

### 1. H3 Motion Context（by NikoDemon80）
- GitHub：`github.com/NikoDemon80/ComfyUI-H3-Motion-Context`
- 核心思路：**接力** — 上一段尾部帧+音频喂给下一段作为起点
- 解开 ComfyUI 只允许钉首帧/尾帧的限制，支持中间帧
- 音频修复：把钉住音频的时间坐标改写到新段时间线上，让模型知道"这是本段更早时刻的声音"，接缝波形相关度从 0.45 提升到 0.95+

### 2. MiniMax H3 Director（by AIMixer）
- GitHub：`github.com/AIMixer/ComfyUI_MiniMaxH3_Director`
- 导演台插件：可视化管理多段时间轴
- 配合 Motion Context 实现"段间引导"，替代手动焊线

## Director 解决的痛点

| 以前（手动焊线） | 现在（导演台引导） |
|---|---|
| Save/Load 节点糊一片 | 时间轴拖拽切分 |
| 手动管 clip_index 编号 | 自动管理段编号 |
| 显存一爆全段重来 | 段间自动清理显存 |
| 改一段怕牵连整链 | 勾选哪段重跑哪段 |

### Director 核心功能
- **可视化时间轴**：拖拽切分，每段范围和缩略图可见
- **段间自动清显存**：每跑完一段自动卸载模型、清空缓存
- **分段落盘**：每段成功即存为 mp4，中途失败不丢前面的
- **局部重跑**：只勾不满意的重跑，其余用缓存
- **六种任务模式**：文生/图生/首尾帧/参考主体/视频转视频/参考改视频

## 推荐配置

```
Motion Context:
  context_length = 22        # 上一段"带过来"的帧数，22帧几乎无缝
  audio_context_length = 22
  用 context_latent 传递     # 别用老的"帧+音频分别传"，会有可见接缝
  关掉 Spectrum 跳步          # 会让接缝处音频变闷

Director:
  打开「段间清理显存」
  导出选「分段导出」
  分辨率全程保持一致           # latent无法缩放，变了会拒跑
  其余按默认走
```

## 关键注意事项

1. `context_length` 选 22 帧，几乎无缝；再长会浪费每段近 1 秒渲染时间
2. 必须用 latent 传递，不能用老的"帧+音频分别传"方式
3. 关闭 Spectrum 等跳步优化器，否则接缝音频变闷
4. 分辨率中途不能变，latent 无法缩放，变了节点直接拒跑

## 实战案例

- 90 秒人物口播 K 线教程，6 段接力（每段 15 秒）
- 口型与声音全程连续，背景音乐无缝衔接
- 提示词分 6 段编写，全程一镜到底 + 推拉摇移运镜
