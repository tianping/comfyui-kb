# MiniMax H3 电影感 LoRA + Sigma Refiner 工作流

## 摘要

MiniMax H3 开源后社区 LoRA 涌现，经大量实测筛出一套电影感 LoRA（来自「图图的AI世界」），能明显改善 H3 光影、肤质和镜头氛围，对提示词动作/镜头控制损伤较小。高动态镜头搭配亦诚开源的 H3 Sigma Refiner 节点修复拉丝模糊，两者组合形成文戏+武戏完整工作流。

## 正文

### 问题背景

H3 开源后各种 LoRA 冒出，能跑起来的不少，真正让画面质感往上走、又不明显伤害提示词控制的很少。这款电影感 LoRA 在低动态文戏里表现最好（人物近景、暗光场景、慢节奏镜头），画面不只是加滤镜，人物与环境的质感一起往上走。

### 核心问题：文戏好，高动态拉丝

人物动作一快（打斗、大幅度运动），局部轮廓拉丝、画面发虚。这是很多画质 LoRA 的通病——静态截图好看，放进视频里动作一多就暴露问题。

### 解决方案：H3 Sigma Refiner

将亦诚开源的 H3 Sigma Refiner 接入工作流，位置在基础调度器输出的 sigmas 后面。

**H3 Sigma Refiner 节点参数：**
- `extra_steps`: 1
- `start_at_sigma`: 0.70
- `end_at_sigma`: 0.00
- `spacing`: cosine

加上后：高动态画面拉丝和模糊大幅改善，电影感 LoRA 的光影与材质保留，运动画面负面影响再减一层。文戏和武戏放进同一套工作流——文戏保电影质感，高动态交给 Sigma Refiner 修整。

### 步数与出图时间

- 基础工作流 **8 步**可用
- 打斗镜头想更稳可提到 **10-12 步**，调度器用 Beta
- 二采（Second Pass）也能改善画面但耗时太长：10-15 秒画面在 4090 上要跑 20+ 分钟，不推荐
- 更实用做法：**先生成 720P → Topaz 放大**，速度与画质更好平衡

### 最终保留的工作流组合

| 场景 | 方案 |
|------|------|
| 低动态文戏 | 电影感 LoRA 直出 |
| 打斗/大幅度运动 | 电影感 LoRA + H3 Sigma Refiner，步数 8-12 |
| 需要高分辨率 | 720P 成片 → Topaz 放大 |

### 要点总结

社区每天有新 LoRA 和节点，能下载不难，难的是测清楚哪些画面有效、哪一步伤害结果。电影感 LoRA 值得留下，Sigma Refiner 补上了高动态短板，两者组合才是能真正拿来做片子的方案。
